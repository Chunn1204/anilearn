# AniLearn｜互動式演算法學習筆記

A beginner-friendly Traditional Chinese interactive algorithm learning website, built with vanilla HTML/CSS/JavaScript and guided by [AGENTS.md](AGENTS.md).

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a public GitHub repository named `anilearn`.
2. Upload `index.html`, `style.css`, `app.js`, `AGENTS.md`, and `README.md` to its root.
3. Go to **Settings → Pages → Build and deployment → Deploy from a branch**.
4. Select `main` and `/(root)`, then save.
5. The website will be available at `https://YOUR_USERNAME.github.io/anilearn/` after deployment.

## Extend
Follow the lesson schema and quality checklist in `AGENTS.md`.
